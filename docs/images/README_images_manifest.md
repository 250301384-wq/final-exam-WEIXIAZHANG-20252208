# GitHub-ready image package

This package contains README-friendly images for the AeroSense IoT data engineering project.

Included images:

1. `01_architecture_overview.png` — clean project architecture diagram.
2. `02_producer_delivery_summary.png` — producer delivery and anomaly-generation evidence.
3. `03_spark_streaming_datalake_evidence.png` — Spark streaming and three-zone data lake evidence.
4. `04_analytics_partition_pruning.png` — analytics outputs and partition-pruning evidence.
5. `05_rest_api_validation.png` — REST API validation evidence.
6. `06_github_readme_evidence_map.png` — suggested README usage map.

Excluded:

- Development UI screenshots.
- Images dominated by local absolute Windows paths.
- Failed intermediate troubleshooting screenshots.

Suggested repository location:

```text
docs/images/
```
